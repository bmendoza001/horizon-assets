# Imagenes publicas

Guarda aqui fondos, logos e imagenes decorativas para SAP Horizon.

Usa WebP para fotografias y SVG para logos. Nombres sugeridos: fondo-sap-v1.webp y logo.svg.

Este repositorio contiene solo recursos publicos. La captura original de SAP y el proyecto de vista previa permanecen en el espacio de trabajo local.

URL directa de ejemplo (funcionara cuando se suba el archivo):
https://raw.githubusercontent.com/bmendoza001/horizon-assets/main/imagenes/fondo-sap-v1.webp

GitHub Pages puede activarse por separado para publicar estos recursos con una URL github.io.
